# Vendor MIDI Note Maps — Research

Collected 2026-11-21. Read-only research; no code changes.

**Sourcing caveat (applies to every product below):** None of the vendors
publishes a numbered note chart as a normal public web page. GGD's own support
docs and community write-ups confirm "GGD does not publish a numbered note
chart"; Toontrack's official manual and per-library MIDI layouts are behind a
login at toontrack.com/manual and in the app (Help > About Sound Libraries /
MIDI Mapping Layout). Therefore the complete tables below are compiled from the
most credible community source found — **Drumverter** (drumverter.com), a MIDI
drum-mapping/translation service that documents per-engine maps — and are
marked **UNOFFICIAL** throughout. Where an official statement about the map's
*structure* (e.g. "GM Extended") exists from the vendor, it is cited separately.

Note names in the tables use the C-1 convention (Reaper/Logic/Ableton/Cubase/
Studio One); the second value is the C-2 convention (Studio One/Cubase/FL).

### GM-compatible subset (GM notes that land on the right drum)
Officially, SD3's default map is "GM Extended": standard GM percussion notes
(36 kick, 37 sidestick, 38 snare, 39–40, 41–48 toms, 42/44/46 hats, 49/51/53/55/57
crashes & ride, 52 china, 59 ride) are honored. Independent check against the
manual chart (https://whackstudio.com/how-to-use-drum-midi-in-superior-drummer-3):
kick 36 plays SD3's "Kick open" articulation (plain hit on 35), snare 38 = center,
42 closed-hat tip, 43/45/47 toms, 46 open-hat edge 2. Notes 49/51/52/53/57 depend
on the loaded kit (chart in the manual stops before 49); check in the MIDI
Mapping Layout window (added in SD3 3.3.4).

## Conflicts / notes

- GGD kick placement: Invasion uses kick 24 (C1/C0 convention) with toms from
  33 — very different from GM. Modern & Massive ('GGD' map) uses GM-style 36/37.
  These are different maps, not a conflict, but conversion code must treat them
  as distinct.
- EZd3 vs SD3: same Toontrack "GM Extended" base, but cymbal placements differ
  (EZd3: 49 Crash 2 / 51 Ride / 53 Ride Bell; SD3: 49 Crash 2 / 51 Ride Bow Tip /
  52 China / 53 Ride Bell). EZd3 has no china in the standard map.
- Snare Flam appears at 27 for RS Drums but 27 is Hi-Hat Open Edge 3 in the
  Toontrack-style low-register layout — never merge low-register maps blindly.

## Semantic articulation candidates (for tag naming)

Distinct articulation concepts appearing across all products:

- Kick: hit, alt/left-beater, (SD3: open vs closed)
- Snare: center/full, rimshot, rim, sidestick, flam, ruff/buzz, off/muted, side
- Toms: rack 1/2/3, floor 1/2/3(/4), rim, rimshot
- Hi-hat openness ladder: tight < closed < loose < open 1..n (GGD: Open 1–3;
  SD3: Open 1–5; RS: Open 1–4); tip vs edge stroke; pedal (chick);
  pedal splash; CC articulations (CC tip/edge/bell, Edge/Tip Trigger);
  aux/second hat
- Ride: bow/tip, edge, bell, bell tip, mute/choke
- Crash: bow/tip, bell, bow, bell tip, mute/choke; multiple crashes
- China: hit, mute/choke; multiple chinas
- Splash: hit, mute/choke; multiple splashes
- Stack: hit, mute/choke
- Bell (dedicated cymbal bell): hit, mute
- Percussion/extras: clap, shaker, tambourine (on-beat/off-beat), snaps
- Hat CC controller channel (CC4-driven openness) as separate from fixed notes
